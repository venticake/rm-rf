# rm-rf

`rm-rf`는 이름만 위험하고 행동은 보수적인 macOS/Ubuntu 디스크 정리 앱입니다. Ubuntu 설치 화면처럼 카드·색상·선택 목록을 갖춘 전체 화면 터미널 UI(TUI)로 동작합니다. 홈 전체나 `Library` 전체를 훑거나 삭제하지 않고, 휴지통·앱 캐시·로그·개발 도구 캐시·오래된 설치 파일처럼 목적이 분명한 영역만 바로 아래 항목 단위로 검사합니다.

## 실행

Python 3.9 이상만 필요합니다.

```sh
chmod +x ./rm-rf
./rm-rf
```

최초 실행은 `rm-rf`의 전체 화면으로 스캔 진행 상황을 보인 뒤 `~/.cache/rm-rf/scan.json`에 결과를 저장합니다. 이후 실행은 캐시를 그대로 보여 줍니다. 다시 실제 용량을 재려면 `r`을 누르거나 다음처럼 실행합니다.

```sh
./rm-rf scan
```

기본 최소 표시 용량은 50 MiB이며, 필요하면 바꿀 수 있습니다.

```sh
./rm-rf scan --min-size 200
```

## 조작법

결과 화면은 현재 여유 공간, 권장 확보 가능 용량, 각 항목의 경로·크기·우선순위·판단 근거를 보입니다.

```text
↑/↓ 또는 j/k     # 후보 이동
Space             # 한 개 이상 선택
Enter 또는 d      # 선택 항목 삭제 (DELETE를 정확히 입력해야 진행)
i                 # 현재 항목의 전체 경로와 근거 보기
a                 # 현재 커서 항목 하나를 Claude CLI로 강제 재평가하고 답변 팝업 표시
r                 # 캐시를 무시하고 새로 측정
q                 # 종료
```

GUI보다 단순한 줄 단위 콘솔을 선호하면 `./rm-rf --plain`을 사용합니다. 삭제는 항상 대상 목록을 다시 보여 주고 `DELETE`를 정확히 입력해야 진행됩니다. 캐시가 변조되었거나 경로가 안전한 대상 범위를 벗어나면 삭제하지 않습니다. 삭제는 영구적입니다.

## Claude 평가 (선택)

대용량이지만 사용자 백업/의존성처럼 애매한 후보는 새 스캔 때 자동으로 Claude CLI에 보내어 `delete/review/keep` 추천과 근거를 받습니다. 대상은 250 MiB 이상의 `REVIEW` 항목뿐이며, 전송 정보는 경로·크기·수정 시각·분류입니다. 평가 중에는 전체 화면에 Claude 진행 상황이 나타나고, 완료되면 상세 패널(`i`)의 `Claude:` 근거와 추천 상태에서 확인할 수 있습니다.

```sh
./rm-rf scan
```

캐시를 불러오는 것만으로는 Claude를 다시 호출하지 않습니다. 새로 평가하려면 현재 커서의 후보에서 `a`를 누르거나 `r`로 재스캔합니다. `a`는 자동 평가와 달리 현재 항목 하나를 크기·분류와 무관하게 사용자가 직접 Claude에 재평가 요청하고, 답변을 즉시 팝업으로 보여 주는 기능입니다. 자동 Claude 평가를 끄려면 `./rm-rf scan --no-ai`를 사용합니다.

AI 평가는 우선순위와 근거를 보완할 뿐, 삭제 확인을 생략하거나 안전 범위를 넓히지 않습니다. `claude` 명령이 없거나 인증이 만료된 경우에도 일반 스캔과 정리는 계속 가능하며, 앱 화면에 `claude auth login` 안내가 표시됩니다.

## 스캔 범위와 안전 원칙

- macOS: `~/.Trash`, `~/Library/Caches`, `~/Library/Logs`, Xcode/Simulator 캐시, sandbox·group container 캐시, CrashReporter, `~/Downloads`의 30일 지난 설치 파일, 그리고 검토용 iPhone/iPad 백업을 다룹니다. `/Library/Caches`, `/Library/Logs`도 보이지만 권한이 필요할 수 있습니다.
- Ubuntu: XDG 캐시, 휴지통, Flatpak 캐시, Gradle/Cargo/Rustup/Steam 캐시, 검토용 Maven/NuGet 저장소, 그리고 `/var/log`의 회전·압축 로그만 다룹니다. 활성 시스템 로그는 삭제하지 않습니다.
- 문서, 사진, 소스 코드, 앱 번들, `Library` 전체, 브라우저 프로필/개인 메시지, 가상 머신, Docker 이미지/볼륨은 기본 대상이 아닙니다. 특히 Docker·패키지 관리자 데이터는 별도 도구의 prune 명령으로 검토하는 편이 안전합니다.

시스템 항목은 관리자 권한이 없어 건너뛸 수 있으며, 스크립트가 `sudo`를 자동 실행하지는 않습니다.
